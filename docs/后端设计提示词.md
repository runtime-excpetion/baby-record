你是一名资深后端架构师，请帮我设计并实现一个「宝宝成长记录服务」。

这是一个家庭内部使用的宝宝成长记录系统，用于记录宝宝每天的喂养、睡眠、纸尿裤、补剂以及成长事件，并提供查询、统计分析、数据可视化接口。

系统需要具备良好的扩展性，未来支持 AI 分析宝宝成长趋势。


# 一、技术栈要求

## 后端

使用：

- TypeScript
- NestJS
- Prisma ORM
- PostgreSQL
- RESTful API

需要具备生产级项目结构：

- 模块化设计
