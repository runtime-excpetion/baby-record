你是一名资深前端架构师，请基于当前已经完成的 NestJS 后端服务，实现对应的前端应用。

目标：

开发一个「宝宝成长记录 Web App」。

该前端用于家庭日常记录宝宝的喂养、睡眠、纸尿裤、补剂以及成长事件。

要求：

前端代码与现有后端代码保持在同一个仓库中。

不要修改后端业务逻辑，只通过 API 调用已有后端服务。

baby-record-system

baby-record-system

├── apps

│   │
│   └── frontend       （新增 Vue3 前端）
